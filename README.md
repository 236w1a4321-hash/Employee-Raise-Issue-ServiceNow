# Employee Raise Issue - ServiceNow

## 📌 Project Overview

The **Employee Raise Issue** project is a ServiceNow application that allows employees to raise workplace-related issues through the **ServiceNow Service Portal**.

The application uses a **Record Producer** to collect employee information and issue details and create a corresponding record in ServiceNow.

## 🎯 Objectives

- Provide employees with an easy way to report issues.
- Create a simple and user-friendly Service Portal experience.
- Capture employee issue details using a Record Producer.
- Automatically create issue records in ServiceNow.
- Make employee issue management more organized and efficient.

## 🛠️ Technologies Used

- ServiceNow
- Service Portal
- Record Producer
- Service Catalog
- Client Scripts
- UI Policies
- Business Rules
- ServiceNow Tables
